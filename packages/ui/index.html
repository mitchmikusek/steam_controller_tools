Steam Controller Flash Tool

Unlock Bluetooth on your Steam Controller

Flash BLE (Bluetooth) firmware onto your original Steam Controller (2015) directly from your browser. No downloads, no installs — just plug in via USB and click flash.

Features

  • One-click Bluetooth firmware flash with progress tracking
  • Revert to production (dongle-only) firmware anytime
  • Works on Linux, macOS, and Windows via Chrome, Edge, or Vivaldi
  • BLE controller mode guide — switch between Bluetooth and dongle with button combos
  • Haptic feedback testing, LED brightness control, and 14 built-in jingles

How It Works

This tool uses the WebHID API to communicate directly with your Steam Controller's firmware over USB. The BLE firmware adds Bluetooth Low Energy support while keeping dongle compatibility — hold Steam+Y to pair via Bluetooth, or Steam+A to use the dongle.

Open Source

Built with React and TypeScript. Source code available on GitHub. Based on the reverse engineering work of OpenSteamController and SteamControllerTool.
